Adicione rotinas para os dias ou semanas que combinam com você e tarefas pontuais quando surgir algo novo.

02

Escolha hoje

Deslize para a direita para concluir ou para a esquerda para pular. Pular hoje encerra o cartão do dia; Pular esta semana encerra a ocorrência semanal; Pular tarefa encerra uma tarefa pontual.
