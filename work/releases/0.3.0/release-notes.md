# Sliding Tasks 0.3.0 (3)

## English

- Undo Done, Not today, and task removal for five seconds, with accessibility timeout support.
- Export your tasks and history to a backup file.
- Choose a folder for automatic daily backups, keeping the seven newest copies.

## Português (Brasil)

- Desfaça Concluído, Não hoje e a remoção de tarefas por cinco segundos, com suporte ao tempo de acessibilidade.
- Exporte suas tarefas e o histórico para um arquivo de backup.
- Escolha uma pasta para backups diários automáticos, mantendo as sete cópias mais recentes.
