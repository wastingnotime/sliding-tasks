first production release. Version code 8 (0.3.5), already available on Closed
testing - Alpha, was added from Play's bundle library to production. No new
bundle was built or uploaded. Source, signature validation and artifact digests
remain those recorded in `artifacts.json`.

launch notes are recorded exactly in `production-release-notes.txt`. Existing
production country/region selection was preserved (178, as reported by the
Alpha track synced with production). The existing ReTrace mapping is attached.

earlier testing releases; no blocking errors appeared.
